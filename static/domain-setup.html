Why does Render's page open instead of your actual storefront?

There are two common causes when entering alzorcouture.in:

  • Cause 1 — Render Free Tier Inactivity Spin-Down: Render's free tier automatically spins down after 15 minutes of inactivity. When a customer opens the link, Render shows a full-screen message: "Spinning up service... Please wait while your service spins up".
  • Cause 2 — GoDaddy DNS routing: If GoDaddy DNS points to Render, visitors hit Render's server. If you deploy your storefront to Vercel (which is pre-configured with vercel.json), Vercel serverless runs 24/7 with zero cold-start loading screens!

PERMANENT SOLUTION 1 (RECOMMENDED): Point Domain to Vercel (0 Cold Starts)

Vercel never sleeps and never displays any Render loading screen. Customers immediately see your luxury store homepage in Chrome:

  1. In Vercel Dashboard:
    Open your alzor-couture project → Settings → Domains → Add alzorcouture.in and www.alzorcouture.in.
  2. In GoDaddy DNS Manager:
    Delete any existing A records pointing to Render (216.24.57.1) or GoDaddy parking, and add these 2 records:
    Type Name / Host Value / Points to TTL
    A @ 76.76.21.21 1/2 Hour or Default
    CNAME www cname.vercel-dns.com 1/2 Hour or Default
  3. Verification: Within minutes, Vercel verifies SSL and your clothing store opens directly at https://alzorcouture.in with zero delay!

PERMANENT SOLUTION 2: Keep Running on Render with 24/7 Keep-Alive

If you prefer hosting directly on Render without paying $7/month:

  1. Keep Render Awake with Free Automated Ping:
    Create a free account on cron-job.org or UptimeRobot.
    Add a monitor pinging your new health endpoint every 10 minutes:
    https://alzor-couture.onrender.com/healthz
    Because Render receives a ping every 10 minutes, it never spins down and visitors never see the Render spin-up screen!
  2. Verify Custom Domain in Render:
    Render Dashboard → alzor-couture → Settings → Custom Domains → Ensure alzorcouture.in and www.alzorcouture.in show "Verified".
  3. GoDaddy DNS for Render:
    Type Host / Name Points to / Value TTL
    A @ 216.24.57.1 Automatic / 600s
    CNAME www alzor-couture.onrender.com Automatic / 600s

  • RAZORPAY_KEY_SECRET = Your confidential live key secret
  • SITE_URL = https://alzorcouture.in
