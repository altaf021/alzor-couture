Why does alzorcouture.in show an error in Chrome?

The domain alzorcouture.in was purchased, but its DNS records have not yet been linked to the hosting server. A domain name needs two simple DNS records to route visitors to your live website.

Quick 3-Minute Fix to Connect alzorcouture.in

  1. Add the custom domain in Render:
    Log in to dashboard.render.com → Select alzor-couture → Settings → scroll to Custom Domains → Add alzorcouture.in and www.alzorcouture.in.
  2. Add DNS records in your Domain Registrar (GoDaddy, Hostinger, Namecheap, etc.):
    Open your domain DNS Manager and add these 2 records:
    Type Host / Name Points to / Value TTL
    A @ (or blank) 216.24.57.1 Automatic
    CNAME www alzor-couture.onrender.com Automatic
  3. Automatic SSL Activation:
    Within 5 to 15 minutes of DNS propagation, Render will automatically issue a free Let's Encrypt SSL certificate and https://alzorcouture.in will open securely in Chrome.

Razorpay Live Mode Configuration

In your Render Dashboard → Environment tab, configure your live credentials:

  • RAZORPAY_KEY_ID = Your live key from Razorpay Dashboard (starts with rzp_live_...)
  • RAZORPAY_KEY_SECRET = Your confidential live key secret
  • SITE_URL = https://alzorcouture.in
